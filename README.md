# Todo Django TypeScript

To-Do List développée avec Django et TypeScript par Nour Hannachi dans le cadre d'une épreuve de réalisation.

## Fonctionnalités

- Ajouter une tâche
- Modifier une tâche
- Marquer une tâche comme terminée
- Supprimer une tâche
- API REST
- Tests unitaires
- Dockerisation

## Technologies

- Python
- Django
- Django REST Framework
- TypeScript
- SQLite
- Docker

## Lancer le projet

###  Dans le terminal

```bash
pip install -r requirements.txt
python manage.py migrate
npm install
npm run build
python manage.py runserver
